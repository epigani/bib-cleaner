# BibTeX File Cleaner and Sorter

A Streamlit-powered tool that simplifies managing BibTeX files by automatically removing duplicate entries, sorting citations alphabetically, and enhancing overall readability. Ideal for academics and researchers to streamline their reference management.

## Features

- **Upload and Process `.bib` Files**: Easily upload your `.bib` files for processing.
- **Remove Duplicates**: Duplicates are automatically detected and removed.
- **Alphabetical Sorting**: Entries are sorted alphabetically, improving the organization of your bibliographic data.
- **Download Processed Files**: After processing, the cleaned and sorted `.bib` files can be downloaded immediately.

## How to Use

1. **Upload your `.bib` file**: Use the file uploader to add your file to the app.
2. **Process the file**: Click 'Process File' to start the cleaning and sorting.
3. **Download**: Once processing is done, download the file with a single click.

## Technologies Used

- **Streamlit**: Powers the web application interface.
- **Python**: Backend processing with regular expressions and file management.
